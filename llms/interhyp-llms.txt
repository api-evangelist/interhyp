# Interhyp

> Interhyp AG is Germany's leading platform for residential mortgage financing (Baufinanzierung), comparing offers from 500+ loan partners. Its Developer Studio publishes partner REST APIs — the Submission API and Submission Documents API — for integrating mortgage submission workflows, financing applications, documents, logbooks and pre-submission checks. Auth is OAuth 2.0 JWT bearer + an Api-Key header; responses use cursor pagination and RFC 7807 problem+json errors with a traceId. Interhyp is part of ING Group and runs the broker brand Prohyp.

## APIs
- [Interhyp Submission API](https://developer.ehyphome.de/products): financing applications, applicants, households, estates, financial standings, offers, submissions, logbooks, commands, pre-submission checks. Base: https://api.interhyp.de/submission/v2
- [Interhyp Submission Documents API](https://developer.ehyphome.de/products): submission document metadata + binary content + submissions protocol. Base: https://api.interhyp.de/submission
